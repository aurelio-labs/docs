This file contains the VoyageEncoder class which is used to encode text using Voyage

#### batch\_docs

```python
def batch_docs(docs: list[str],
               size: int = VOYAGE_MAX_EMBED_BATCH) -> list[list[str]]
```

Split texts into chunks that fit Voyage&#x27;s per-request input limit.

**Arguments**:

- `docs` (`list[str]`): The texts to embed.
- `size` (`int`): Maximum number of texts per request.

**Returns**:

`list[list[str]]`: The texts split into consecutive chunks of at most ``size``.

## VoyageEncoder Objects

```python
class VoyageEncoder(DenseEncoder, AsymmetricDenseMixin)
```

Class to encode text using Voyage and VoyageAI SDK.
Requires a Voyage API key from https://voyageai.com/api-keys/

#### \_\_init\_\_

```python
def __init__(name: str | None = None, api_key: str | None = None)
```

Initialize the VoyageEncoder.

**Arguments**:

- `name` (`str`): The name of the embedding model to use such as &quot;voyage-3-lite&quot;.
- `api_key` (`str`): The Voyage API key, can also be set via the VOYAGE_API_KEY
environment variable.

**Raises**:

- `ValueError`: If no API key is provided or found in the environment.
