## LocalIndex Objects

```python
class LocalIndex(BaseIndex)
```

#### add

```python
def add(embeddings: List[List[float]],
        routes: List[str],
        utterances: List[Any],
        metadata_list: Optional[List[Dict[str, Any]]] = None,
        sparse_embeddings: Optional[List[SparseEmbedding]] = None,
        **kwargs)
```

Upsert records into the index, one per (route, utterance) pair. A pair

that is already stored has its embedding and metadata replaced.

**Arguments**:

- `embeddings` (`List[List[float]]`): List of embeddings to add to the index.
- `routes` (`List[str]`): List of routes to add to the index.
- `utterances` (`List[str]`): List of utterances to add to the index.
- `metadata_list` (`Optional[List[Dict[str, Any]]]`): List of metadata to add to the index.
- `sparse_embeddings` (`Optional[List[SparseEmbedding]]`): Not supported, use HybridLocalIndex.

#### query

```python
def query(
    vector: np.ndarray,
    top_k: int = 5,
    route_filter: Optional[List[str]] = None,
    sparse_vector: dict[int, float] | SparseEmbedding | None = None
) -> Tuple[np.ndarray, List[str]]
```

Search the index for the query and return top_k results.

**Arguments**:

- `vector` (`np.ndarray`): The vector to search for.
- `top_k` (`int`): The number of results to return.
- `route_filter` (`Optional[List[str]]`): The routes to filter the search by.
- `sparse_vector` (`dict[int, float] | SparseEmbedding | None`): The sparse vector to search for.

**Returns**:

`Tuple[np.ndarray, List[str]]`: A tuple containing the query vector and a list of route names.

#### aquery

```python
async def aquery(
    vector: np.ndarray,
    top_k: int = 5,
    route_filter: Optional[List[str]] = None,
    sparse_vector: dict[int, float] | SparseEmbedding | None = None
) -> Tuple[np.ndarray, List[str]]
```

Search the index for the query and return top_k results. Note that this

just points to the sync query method, the computation is local and CPU-bound.

**Arguments**:

- `vector` (`np.ndarray`): The vector to search for.
- `top_k` (`int`): The number of results to return.
- `route_filter` (`Optional[List[str]]`): The routes to filter the search by.
- `sparse_vector` (`dict[int, float] | SparseEmbedding | None`): The sparse vector to search for.

**Returns**:

`Tuple[np.ndarray, List[str]]`: A tuple containing the query vector and a list of route names.
