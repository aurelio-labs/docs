a router that asks a decision model which route applies. one call answers many questions.

## DecisionRouter Objects

```python
class DecisionRouter(BaseRouter)
```

routes by asking a decision model one choice question: which route applies.

**Arguments**:

- `model`: The decision model that answers, e.g. `TypeSafeDecisionModel()`
over HTTP.
- `routes`: The routes to choose between.
- `instructions`: The question asked about each query.
- `confidence_threshold`: The confidence a route needs, unless it sets its own.
- `calibrator`: A fitted score -&gt; probability map; `fit()` makes one.

def route_question() -> Question

async def aask(state: object, questions: dict[str,
