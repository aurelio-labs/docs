## Route Objects

```python
class Route(BaseModel)
```

A route: one decision a router can make, and what tells it when to make it.

**Arguments**:

- `name` (`str`): The name of the route.
- `utterances` (`List[Any]`): Example queries for the route. Indexed routers embed these; a
decision router only reads them when the route has no description.
- `description` (`Optional[str]`): What the route covers, stated literally. Decision routers
read it.
- `confidence_threshold` (`Optional[float]`): The confidence a router needs before it returns this
route. It overrides the router&#x27;s own confidence_threshold.
- `metadata` (`Dict[str, Any]`): Anything else to keep with the route.
