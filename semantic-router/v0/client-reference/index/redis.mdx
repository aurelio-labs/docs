## RedisIndex Objects

```python
class RedisIndex(BaseIndex)
```

Redis implementation of Index, backed by RediSearch vector search.

Requires a Redis server with the RediSearch module (e.g. Redis Stack, or
Redis 8+, which bundles it by default). Plain open-source Redis without
the module cannot be used, since it has no vector index type.

#### add

def add(embeddings: List[List[float]],
        routes: List[str],
        utterances: List[str],
        function_schemas: Optional[List[Dict[str, Any]]] = None,

        batch_size: int = DEFAULT_UPLOAD_BATCH_SIZE,

- `metadata_list` (`List[Dict[str, Any]]`): The metadata to add.
- `List[List[float]]`0 (`List[List[float]]`1): The batch size to use for the upload.

#### query

```python
def query(
    vector: np.ndarray,
    top_k: int = 5,
    route_filter: Optional[List[str]] = None,
    sparse_vector: dict[int, float] | SparseEmbedding | None = None
) -> Tuple[np.ndarray, List[str]]
```

Query the index.

**Arguments**:

- `vector` (`np.ndarray`): The vector to query.
- `top_k` (`int`): The number of results to return.
- `route_filter` (`Optional[List[str]]`): The route filter to apply.
- `sparse_vector` (`dict[int, float] | SparseEmbedding | None`): Unused; RedisIndex does not support hybrid search.

**Returns**:

`Tuple[np.ndarray, List[str]]`: A tuple of the scores and route names.
